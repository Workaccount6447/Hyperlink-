  <summary><b>Deploy on Windows or other plataform<b></summary>
  
  You should make sure you have Python 3.6+ installed on your PC, then clone this repo and run the following commands in a terminal:

```py
git clone https://github.com/biisal/biisal-file-stream-pro
cd filestreambot-pro
virtualenv -p /usr/bin/python3 venv
. ./venv/bin/activate
pip install -r requirements.txt
python3 -m biisal
```



and to stop the whole bot,
 do <kbd>CTRL</kbd>+<kbd>C</kbd>

<details>
  <summary><b>Vars and Details :</b></summary>

Go to a file named `Sample.env` and see all the variables and it on the env column of your hosting.
An example of `sample.env` file:

```py
APP_BASE_URL=www.example.koyeb.app
DATABASE_URL=Postersql.in
TELEGRAM_BOT_TOKEN=Your_Bot_Token
TELEGRAM_CHAT_ID=-100xxxxxxxxx
```
  
`TELEGRAM_BOT_TOKEN` : Get the bot token from [@BotFather](https://telegram.dog/BotFather)

`TELEGRAM_CHAT_ID` : Create a new channel (private/public), add [@missrose_bot](https://telegram.dog/MissRose_bot) as admin to the channel and type /id. Now copy paste the ID into this field.

`DATABASE_URL` : Postersql URI for saving metadata when they uploading the file . We will use that for permanent links. I will try to add more features related with Database.

`APP_BASE_URL` :  A Fully Qualified Domain Name if present. Defaults to `WEB_SERVER_BIND_ADDRESS` </details>
